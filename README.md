# WS2812

ESP32와 Adafruit NeoPixel 라이브러리로 WS2812 LED 8개를 빨강·초록·파랑 순서로 하나씩 켜는 PlatformIO 예제

## 개요

WS2812(NeoPixel) 주소 지정형 RGB LED 8개를 데이터 핀 하나로 제어합니다. 의도한 동작은 마지막 LED(인덱스 7)부터 첫 LED(인덱스 0)까지 0.5초 간격으로 하나씩 빨간색으로 켜고, 이어서 초록색, 파란색으로 같은 과정을 반복하는 것입니다. 단, 현재 코드에는 반복문 조건 오류가 있습니다([참고](#참고) 참조). 작성 시기는 2024년 10월입니다(커밋 기록 기준).

## 하드웨어

- 보드: DOIT ESP32 DevKit V1 (`board = esp32doit-devkit-v1`)
- 출력: WS2812 RGB LED 8개 (`ledNum 8`, 색 순서 `NEO_GRB`, 800 kHz `NEO_KHZ800`)

| 신호 | GPIO |
|------|------|
| WS2812 데이터 입력 (`ledPin`) | 15 |

## 동작 방식

1. `setup()`: `pixels.begin()`으로 NeoPixel 출력을 초기화합니다.
2. `loop()`: 색마다 다음 과정을 반복하도록 작성되어 있습니다.
   - `pixels.clear()`로 버퍼를 지웁니다.
   - 인덱스 7부터 1씩 줄이며 `setPixelColor(i, Color(...))` 후 `show()`, 500 ms 대기
   - 색 순서: 빨강 `(255, 0, 0)` → 초록 `(0, 255, 0)` → 파랑 `(0, 0, 255)`

## 개발 환경

| 항목 | 값 |
|------|----|
| 도구 | PlatformIO |
| 플랫폼 | `espressif32` |
| 프레임워크 | `arduino` |
| 라이브러리 | `adafruit/Adafruit NeoPixel @ ^1.10.6` |
| 모니터 속도 | `monitor_speed = 115200` (코드에서 시리얼은 사용하지 않음) |

## 빌드 및 업로드

```bash
pio run -t upload
```

라이브러리는 첫 빌드 때 `lib_deps`에 따라 자동으로 설치됩니다.

## 참고

- 세 반복문 모두 `for (int i = 7; i < ledNum; i--)` 형태입니다. `i`를 줄이면 0 아래로 내려가도 `i < 8`이 계속 참이라 첫 번째(빨강) 반복문이 사실상 끝나지 않습니다. 음수 인덱스는 라이브러리가 무시하므로 8개가 모두 빨간색으로 켜진 뒤 그 상태로 멈춘 것처럼 보이고, 초록·파랑 단계로 넘어가지 않습니다.
- 의도대로 동작시키려면 조건을 `i >= 0`으로 바꾸면 됩니다.

  ```cpp
  for (int i = ledNum - 1; i >= 0; i--) { ... }
  ```
